# Контроль магнитной печи

Windows-приложение на .NET 8 и Avalonia для расчёта времени окончания профиля магнитной печи.

Одновременно поддерживаются четыре независимые печи: **#4, #5, #6 и #7**. Переключатель в верхней
части окна показывает состояние каждой печи; профиль, время запуска, этапы и таймер сохраняются отдельно.

Интерфейс доступен на русском, румынском и английском языках. Язык меняется в правом верхнем углу без
перезапуска и запоминается для следующего открытия программы.

## Как пользоваться

1. Нажмите **Из облака…** и выберите профиль из подключённой папки SharePoint/OneDrive либо
   нажмите **Файл на ПК…** для обычного локального Excel.
2. Сначала выберите нужную печь **#4–#7**, затем укажите фактические дату и время её запуска по часам Windows.
3. Проверьте рассчитанное поле **Извлечь из печи** и нажмите **Запустить**.
4. Во вкладке **Ход процесса** отображаются текущий этап и два обратных отсчёта.
5. Во вкладке **Статичное расписание** показаны абсолютные времена начала и окончания всех этапов.

Во вкладке **Ход процесса** также отображается предполагаемый температурный профиль. Вертикальный
RTC-маркер движется по графику в соответствии с текущим временем Windows; рядом показаны расчётная
температура, уставка этапа, скорость изменения и прошедшее время. Это расчёт по Excel, а не показание датчика.

Приложение распознаёт таблицу по заголовкам `Step`, `Segment Label`, `Set Temp (C°)`,
`Rates (C°/min)` и `Time to set Temp (min)`. Пустое название этапа заменяется на «Этап N».

## Профили из SharePoint

1. В браузере SharePoint откройте папку с профилями и один раз нажмите **Add shortcut to OneDrive**
   («Добавить ярлык в OneDrive»). На рабочем ПК должен быть запущен OneDrive с корпоративной учётной записью.
2. В приложении нажмите **Из облака…**, затем укажите добавленную папку (например `AnnealingResults`).
3. Дальше приложение запоминает эту папку, показывает все `.xlsx`/`.xlsm` внутри неё и вложенных папок,
   позволяет искать по имени или папке и фильтровать по дате изменения.

При включённом Files On-Demand список и поиск работают по облачным метаданным. Содержимое выбранного Excel
OneDrive загрузит автоматически только в момент открытия. Приложение не хранит пароль Microsoft 365.

## Сон, выключение и RTC

Запуск сохраняется в `%LocalAppData%\MagneticFurnaceTimer\active-run.json` как абсолютное UTC-время.
Обратный отсчёт не является накопительным таймером процесса: каждую секунду положение вычисляется заново
по системным часам Windows. После сна или перезапуска приложение сразу показывает актуальный этап.

Важно: точность результата зависит от правильности часов и часового пояса Windows. Для рабочего мини-ПК
рекомендуется включить автоматическую синхронизацию времени.

Приложение является вспомогательным средством отображения и не заменяет штатную автоматику,
аварийную защиту, технологические инструкции или независимый контроль оператора.

## Сборка

```powershell
dotnet build MagneticFurnaceTimer.sln -c Release
dotnet test MagneticFurnaceTimer.sln -c Release
dotnet publish MagneticFurnaceTimer.csproj -c Release -r win-x64 --self-contained true -p:PublishSingleFile=true
```
